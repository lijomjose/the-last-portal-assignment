The Last Portal — Data Structures Assignment

Repair a small C game and help Caitlyn find her way home. Implement six missing stack, queue and linked-list functions, then diagnose two faulty controllers. Each repair restores something you can use in the game. The aim is to build your own problem-solving skills and confidence through tracing, debugging and making your code work.

The package includes the unfinished project, a completed reference game for Windows and Linux without solution source, a detailed handout, and build-and-debug launchers. Extract everything and begin with START_HERE.txt. Complete the repairs yourself and follow the handout and course portal for submission requirements.
